## 加载与备份

准备完整的 fx-5800P 型号目录、e5800p 镜像和兼容的 CasioEmuMsvc。型号应包含 ROM、`config.bin`、Flash 和 RAM/SRAM 文件。模拟器补丁与构建方法见 [模拟器说明](emulator.md)。

保留已有 PROGRAM 时，先执行原生 OFF 保存，再用型号最新的 `flash.dmp` [升级固件](../README.md#升级已有修改版)。完整目录副本用于恢复 ROM、配置和 SRAM/PRAM 等状态。

以下命令从项目根目录的 PowerShell 执行。

1. 在源型号中 [保存程序并关闭模拟器](#在模拟器中保存程序)。
2. 输入路径。副本目录选在源目录之外，使用一个待创建的目录名。

   ```powershell
   $SourceModel = Read-Host '完整源型号目录'
   $Model = Read-Host '新型号副本目录'
   $Image = Read-Host '要加载的固件文件路径'
   $Exe = Read-Host '兼容的 CasioEmuMsvc.exe 路径'
   ```

3. 克隆型号：

   ```powershell
   python tools/casio_tool.py model clone "$SourceModel" "$Model"
   ```

4. 克隆成功后部署镜像：

   ```powershell
   python tools/casio_tool.py model deploy "$Image" --model "$Model"
   ```

5. 部署成功后启动副本：

   ```powershell
   python tools/casio_tool.py model start --exe "$Exe" --model "$Model"
   ```

部署同步 `flash.bin` 与 `flash.dmp`，保留 ROM、配置和 RAM/SRAM。部署前须关闭模拟器；CLI 会检查型号是否仍被进程使用。

### 在模拟器中保存程序

保存程序后，用原生 OFF 完成 SRAM 到 Flash 的备份，再关闭窗口：

1. 按 SHIFT → AC/ON（OFF）。
2. 在项目根目录检查该型号的状态：

   ```powershell
   $Model = Read-Host '当前运行的型号目录'
   python tools/casio_tool.py debug --model "$Model" status
   ```

3. 确认 `run_status=0` 后等至少 12 秒，核对型号目录中 `flash.dmp` 的更新时间。
4. 正常关闭模拟器窗口。

模拟器每 10 秒将 Flash 内容写入 `flash.dmp`。关机签名出现时，ROM 可能仍在备份 SRAM，因此关闭窗口前要按第 3 步检查保存结果。冷启动会恢复上次原生备份，保存中途复位可能恢复较早的程序版本。

重新启动同一型号副本，打开并运行 PROGRAM，检查保存结果。

## GRAPH 绘图与分析

1. 按 MODE → 7 → 1:GRAPH。
2. 在原生 `f(X)` 编辑器输入 `X²`，按 EXE 确认。
3. 曲线出现后按 FUNCTION → 1:TRACE。
4. 按 EXE 输入精确 X 值 `2`，确认后查看 `X=2、Y=4`。
5. 按 EXIT 回绘图；再次 EXIT 回 GRAPH/TABLE 选择页。

初始 X、Y 视窗均为 −10…10，正文绘图区为 96×31 像素，顶端保留状态行。曲线在定义域边界和可疑不连续处断开。

### 改公式、平移和缩放

| 当前页面 | 按键 | 结果 |
| --- | --- | --- |
| 普通绘图 | EXE | 打开共享的原生 `f(X)` 编辑器；EXE 保存，EXIT 取消本次编辑。 |
| 普通绘图 | 方向键 | 按当前视窗宽/高的四分之一平移。 |
| 普通绘图 | SHIFT → 上/下 | 以光标为中心放大/缩小两倍。 |
| 追踪 | 左/右、EXE | 按一列移动，或输入精确 X；底部显示原生数值 X/Y。 |
| 普通绘图 | FUNCTION | 打开 `TRACE / CALC / VIEW / SKETCH` 数字菜单。 |

按 FUNCTION → 3:VIEW，依次选择 `xmin / xmax / ymin / ymax` 并输入范围。两组最小值均须小于最大值，出现 `BAD WINDOW` 后继续修正。VIEW 页按右键，选 `1:RESET` 恢复初始视窗。

### 求零点、极值、积分和斜率

1. 按 FUNCTION → 2:CALC。
2. 第一页选 `1:ROOT / 2:MIN / 3:MAX / 4:SLOPE`；右键翻到第二页选 `1:INTEGRAL`。
3. 按提示输入区间端点；SLOPE 输入求导位置 X。
4. 查看 X/Y 或结果。极值可能附带 `ENDPOINT`（端点）或 `FLAT`（常值）标记。
5. 按 EXE 或 EXIT 继续。SLOPE 显示 `ADD TANGENT?`：EXE 保存切线，EXIT 保留当前草图；INTEGRAL 显示稀疏阴影，再按 EXE 或 EXIT 回曲线。

计算取消键以页面提示为准：分段计算使用 EXIT，原生长计算使用 AC。

例如 `X²−2` 在 [1,2] 的 ROOT 约为 `1.4142135623731`，`X²` 在 [0,1] 的 INTEGRAL 约为 `0.333333333333333`。计算沿用当前角度设置。

| 提示 | 操作 |
| --- | --- |
| `UNDEFINED` | 检查函数定义域、尖点及复数结果，选择有效区间。 |
| `NO ROOT` / `UNCONFIRMED` | 缩小区间或移动追踪位置；`UNCONFIRMED` 保留候选 X/Y 供检查。 |
| `NO CONVERGENCE` | 调整区间、视窗或求值位置，再运行。 |
| `UNSTABLE` | 检查公式的变量写入等副作用，使相同 X 可重复得到相同结果。 |
| `MEMORY FULL` / `NAME USED` | 通过系统 MEMORY 释放空间，或检查 `main/E5GRAPH`、`main/E5GWORK` 同名对象。 |

### 添加草图

1. 按 FUNCTION → 4:SKETCH。
2. 第一页选 `POINT / LINE / RECT / TEXT`；右键第二页选 `PEN / UNDO / CLEAR`。
3. 方向键移动十字，EXE 确认点；线和矩形依次确认两端。TEXT 在原生输入器中输入 ASCII `20–5F` 范围的字符。
4. PEN 用 EXE 切换落笔/抬笔，方向键续画，EXIT 提交整笔；UNDO 撤销最后一个完整对象。
5. 退出前按 [关机保存步骤](#在模拟器中保存程序) 保存视窗和草图。

草图保存数学坐标，平移和缩放时随曲线重绘，出窗部分裁剪。CLEAR 经确认后清除草图，保留公式。`main/E5GRAPH` 保存视窗和对象。对象损坏时显示 `RESET GRAPH?`，EXE 重建，EXIT 保留原数据。

### 使用原生 TABLE

按 MODE → 7 → 2:TABLE，输入公式并设置 Start、End、Step，查看原生数值列表。TABLE 与 GRAPH 共用 `f(X)`；在任一入口修改后，另一入口会读取最新公式。

## Add-in 应用

先按 [构建并安装 HELLO](5800p-kits.md#构建并安装-hello) 备份 S4、安装应用并部署型号副本。

配套 fx-5800P 型号在计算页面按电脑键盘 F10 进入 Devlop Mode；`model.lua` 将该键映射为原生开发键 `40h`。

1. 打开 Devlop Mode → 6:Add-in，按应用前的数字运行；左右键翻页。
2. HELLO 显示文字后按 EXIT，启动器显示 `RETURN 42`；EXE 回应用列表。
3. 退出前执行原生 OFF 保存，再正常关闭窗口。

S4 的 64 KiB 由应用与原生 Built-in/YAMAYO 库切换使用。原库备份用于整区恢复，操作命令见 [替换、删除与恢复](5800p-kits.md#替换删除与恢复)。原生写库或 Release 覆盖应用前显示 `ERASE APPS?`，EXE 继续，EXIT 保留应用。

Hex 修改代码后，启动器显示 `APP MODIFIED`：选 `1:RUN` 运行当前机器码，`2:BACK` 返回。应用使用作者声明的工作区与栈，变量修改和返回行为由应用管理。

## ASM 的 Disas／Hex 视图

从 MODE → 5:PROG → 2:ASM 进入。按 SHIFT → 左/右 切换 Disas 和 Hex，两种视图共用当前地址。系统内存管理从 MODE → ↓ → 1:MEMORY 打开。

首次查看使用 R 模式。写入前备份完整型号：RAM/SRAM 中包含原生文件、变量、显示缓冲和活动栈，覆盖这些位置可能立即破坏运行状态。

| 底行模式 | 操作 |
| --- | --- |
| P：编程 | 上/下按指令移动并滚动；FUNCTION 打开指令菜单。三行小字显示地址、机器码、助记符和操作数，选中指令反色。 |
| R：读取 | 四行、每行八字节；左右移动一字节，上/下移动八字节，跨页保持列位置。长按连续移动和翻页，松开停止。可写区域按 EXE 进入 W。 |
| W：写入 | 输入两位十六进制修改暂存页；EXE 保存，EXIT 放弃，随后回到 R。 |

十六进制 A～F 用 ALPHA → 1～6 输入。W 模式输入第一位时底行显示 `A_`，两位完成后更新页面并出现 `*`。方向键选择本页其他字节；输入一半时按左键清除该字节的输入。

P 指令队列或 W 页面有待保存内容时，须先提交再切换、跳转或跨页；`SAVE FIRST` 会保留待存内容。R 按 EXIT 返回 PROG/ASM 选择页。Flash 保存涉及整扇区处理，等底行恢复 R 后继续操作。

### 查看长指令

Disas 标题用反色标明当前视图；Hex 从第一行开始显示数据。底行显示绝对地址、当前值和模式。

反汇编行超过 24 字符时，末尾显示 `+`。单独按右键展开所选指令的机器码与完整操作数，长文本分成两行；左键或 EXIT 返回列表。

普通指令占两字节，带地址、位移或远跳转的指令通常占四字节，`SUB R,#` 宏按完整八字节显示。L/ST 的立即段、寄存器段和复用 DSR 前缀与内存操作合并显示。分支显示绝对目标，远调用显示 CSR:PC；7 位立即数和 SP 立即数使用与菜单一致的原始十六进制位编码。寄存器按 R、ER、XR、QR 组显示。

### GOTO 地址跳转

按 SHIFT → FUNCTION。P 输入四位十六进制 PC，取偶数地址 4000～5FEE。Hex 先选区域，再输入地址：

| 区域 | CPU 地址 | 输入示例 | Hex 写入范围 |
| --- | --- | --- | --- |
| `1:FLASH` | `8:0000～F:FFFF`，512 KiB | 五位 `84000` → `8:4000`；`FFFFF` → `F:FFFF` | S1 用户区 `8:4000～5FEF` |
| `2:SRAM` | `4:0000～4:7FFF`，32 KiB | 四位 `1234` → `4:1234` | 整个范围 |
| `3:RAM` | `0:8000～0:8DFF`，3.5 KiB | 四位 `8600` → `0:8600` | 整个范围 |

EXE 跳转，左键退回一位，EXIT 取消。输入满位数后继续输入会从头开始；选区域后直接按 EXE 使用显示的默认地址。

Flash 使用 CPU 地址，例如 `84000` 对应文件物理偏移 `0x4000`。RAM/SRAM 保存只写本页实际改过的字节，其他实时变化的字节保持当前值。从其他区域返回 P 时，恢复进入 Hex 前的编程地址。

### Flash 提交与恢复

页面编辑器使用 S1/S2 journal（事务备份）：

- S1：物理 `[0x4000,0x6000)`；可编辑部分到 `0x5FEF`，末 16 字节为校验元数据，R 可查看。
- S2：物理 `[0x6000,0x8000)`，保存恢复副本。

提交按“备份 S1、擦除重写、核对字节与 CRC-16、写完成标记”的顺序执行。中断提交通过有效 S2 恢复 S1。`WRITE ERROR` 保留页面供排查；`RECOVER ERROR` 需要在 PC 恢复完整 Flash 备份。

BASIC 的 FLASHWRITE/ASM 使用原始编程，CALL 直接调用目标；擦除、备份和恢复由程序作者安排，详见 [Flash 原始编程](BASIC_enhancements.md#flash-原始编程与显式擦除)。

## FUNCTION 指令菜单

P 按 FUNCTION；R 按 FUNCTION 会回到 P 并打开菜单。菜单使用大字和数字直选。

| 页面 | 按键 |
| --- | --- |
| 类别 | 数字 1～6：ARITH、MOVE、BR、LOADST、STACK、MISC；EXIT 返回 P |
| 指令 | 每页四行，数字 1～4 选择；左/右翻页，首尾循环，尾页空行编号保持当前页；EXIT 返回类别 |
| 操作数 | 数字键输入，ALPHA → 1～6 输入 A～F；左键回退，右键或 EXE 前进 |
| 机器码预览 | EXE 暂存到 RAM 队列；`NEXT 4002 Q02` 表示下一条 PC 与待保存字节数 |

L/ST 字段后有 `SEG --`：输入 0～F 添加立即段前缀，DEL 恢复 `--`，EXE 接受，EXIT 取消。`--` 使用原生单指令访存。XR 选择 0/4/8/12，QR 选择 0/8。

### 保存两条指令

此例写入 `8:4008` 起的四个字节。先在型号副本中备份 S1，并确认目标空间可供使用。

1. 用 GOTO 选择 4008。
2. 按 FUNCTION → 2:MOVE → 1:MOV R,#，输入 0、0、1、EXE；预览应为 `01 00`，再按 EXE 暂存。
3. 按 FUNCTION → 6:MISC → 右 → 右 → 2:END；预览应为 `1F FE`，再按 EXE 暂存。
4. 按 SHIFT → EXE 保存队列，切换 R 读回 `8:4008`，应得到 `01 00 1F FE`。

队列最多 64 字节，超出时先提交已有内容。P 按 EXIT 后，EXE 保存并退出，EXIT 放弃并退出。

条件分支输入四位绝对目标 PC，按 `(目标−(当前 PC+2))/2` 编码；奇目标、扇区越界和距离越界分别报错。JMP/CALL 使用段 8 的四位 PC；END 编码为原生 RET（`1F FE`）。核验已保存的机器码后，按 ALPHA → EXE 执行。

## BASIC 与公共入口

在原生 PROGRAM 编辑器按 FUNCTION → 右 → 1:NX 使用 e.basic。按键教程与程序见 [BASIC 入门](BASIC_enhancements.md)，参数和副作用见 [语言参考](e.basic.md)。

共享小字入口为 F:9000，指针表和补充字模位于 F:9400 / F:9480。使用旧段 9 入口的汇编须按新地址重编译；段 9 用于原生程序库或 Add-in。接口、字符范围和状态恢复见 [小字体参考](ROM_small_font.md)。

## 关机签名

按 SHIFT → AC/ON（OFF）显示 Ziyang-Bai 签名，再按 AC/ON 恢复计算界面。关闭模拟器前，按[关机保存步骤](#在模拟器中保存程序)保存程序和数据。

修改图案时，编辑 [`ziyang_bai.pbm`](../firmware/e5800p/ziyang_bai.pbm)，保持 96×32 像素，`1` 表示黑色，再重新[构建固件](../README.md#从原厂-flash-构建)。资源采用 ASCII PBM，构建时打包为 384 字节，每行 12 字节，高位在左。
