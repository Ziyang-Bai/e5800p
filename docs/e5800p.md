## 加载与备份

准备完整的 fx-5800P 型号目录、已生成的 e5800p 镜像和兼容的 CasioEmuMsvc。型号应包含 ROM、`config.bin`、Flash 和 RAM/SRAM 文件。配套模拟器的补丁与构建方法见 [模拟器说明](emulator.md)。

已有 PROGRAM 要保留时，先执行原生 OFF 保存，再以型号最新的 `flash.dmp` 作为 [升级输入](../README.md#升级已有修改版)。完整目录副本用于恢复 ROM、配置和 SRAM/PRAM 等状态。

以下命令从项目根目录的 PowerShell 执行。

1. 在源型号中 [保存并正常关闭模拟器](#原生-program-的模拟器持久化)。
2. 输入路径。副本目录选在源目录之外，使用一个待创建的目录名。

   ```powershell
   $SourceModel = Read-Host '完整源型号目录'
   $Model = Read-Host '新型号副本目录'
   $Image = Read-Host '要加载的固件文件路径'
   $Exe = Read-Host '兼容的 CasioEmuMsvc.exe 路径'
   ```

3. 克隆型号：

   ```powershell
   python tools/casio_tool.py model clone "$SourceModel" "$Model"
   ```

4. 克隆成功后部署镜像：

   ```powershell
   python tools/casio_tool.py model deploy "$Image" --model "$Model"
   ```

5. 部署成功后启动副本：

   ```powershell
   python tools/casio_tool.py model start --exe "$Exe" --model "$Model"
   ```

部署同步 `flash.bin` 与 `flash.dmp`，保留型号中的 ROM、配置和 RAM/SRAM。部署时模拟器须处于关闭状态；CLI 会检查型号是否仍被进程使用。

### 原生 PROGRAM 的模拟器持久化

保存程序后，用原生 OFF 完成 SRAM 到 Flash 的备份，再关闭窗口：

1. 按 **SHIFT → AC/ON（OFF）**。
2. 在项目根目录检查该型号的状态：

   ```powershell
   $Model = Read-Host '当前运行的型号目录'
   python tools/casio_tool.py debug --model "$Model" status
   ```

3. 确认 `run_status=0` 后等至少 **12 秒**，核对型号目录中 `flash.dmp` 的更新时间。
4. 正常关闭模拟器窗口。

模拟器每 10 秒保存一次 `flash.dmp`。签名出现后，ROM 仍可能在备份 SRAM；上述等待让原生保存和宿主落盘都有机会完成。冷启动会恢复上次原生备份，保存中途复位可能恢复较早的程序版本。

冷启动同一副本后，重开并运行 PROGRAM 检查保存结果。运行中直接关闭窗口采用宿主退出流程；需要保留原生编辑时使用上述 OFF 流程。

## TABLE 绘图

1. 打开 **MODE → 7:TABLE**，输入 `f(X)=1`。
2. 按 EXE，将 Start、End、Step 分别设为 **1、5、1**。
3. 在数值列表按 **EXIT**，图形页应显示水平线。

图形页按 EXIT 回到区间设置，再按 EXIT 回到公式编辑。其他函数沿相同路径输入。

绘图使用 96×32 像素和自适应 Y 量程，最多读取 255 个采样点。相邻有效点连线，原生无效点和采样跨越极点的位置断线。例如 `10^10+X` 在 X=1…5 时仍能显示上升趋势；计算使用 TABLE 的 15 位 BCD 有效数字与有符号 64 位整数完成量程和像素换算。

## ASM 的 Disas／Hex 视图

从 **MODE → 5:PROG → 2:ASM** 进入。按 **SHIFT → 左/右** 在 Disas 和 Hex 之间切换，两种视图共用当前地址。系统内存管理仍从 **MODE → ↓ → 1:MEMORY** 打开。

首次查看使用 R 模式。写入前备份完整型号：RAM/SRAM 中包含原生文件、变量、显示缓冲和活动栈，覆盖这些位置可能立即破坏运行状态。

| 底行模式 | 操作 |
| --- | --- |
| **P：编程** | 上/下按指令移动并滚动；FUNCTION 打开指令菜单。三行小字显示地址、机器码、助记符和操作数，选中指令反色。 |
| **R：读取** | 四行、每行八字节；左右移动一字节，上/下移动八字节，跨页保持列位置。长按连续移动和翻页，松开停止。可写区域按 EXE 进入 W。 |
| **W：写入** | 输入两位十六进制修改暂存页；EXE 保存，EXIT 放弃，随后回到 R。 |

十六进制 A～F 使用 **ALPHA → 1～6**。W 模式输入第一位时底行显示 `A_`，两位输入完成后更新页面并出现 `*`。方向键选择本页其他字节；输入一半时按左键清除该字节的输入。

P 的指令队列或 W 的页面有待保存内容时，先提交再切换、跳转或跨页；`SAVE FIRST` 会保留这些内容。R 模式按 EXIT 返回 PROG/ASM 选择页。Flash 保存涉及整扇区处理，等底行恢复 **R** 后继续操作。

### 查看长指令

Disas 标题用反色标明当前视图；Hex 从第一行开始显示数据。底行显示绝对地址、当前值和模式。

反汇编行超过 24 字符时，末尾显示 `+`。单独按 **右键** 展开所选指令的机器码与完整操作数，长文本分成两行；左键或 EXIT 返回列表。

普通指令占两字节，带地址、位移或远跳转的指令通常占四字节，`SUB R,#` 宏按完整八字节显示。L/ST 的立即段、寄存器段和复用 DSR 前缀与内存操作合并显示。分支显示绝对目标，远调用显示 CSR:PC；7 位立即数和 SP 立即数使用与菜单一致的原始十六进制位编码。寄存器按 R、ER、XR、QR 组显示。

### GOTO 地址跳转

按 **SHIFT → FUNCTION**。P 输入四位十六进制 PC，取偶数地址 **4000～5FEE**。Hex 先选区域，再输入地址：

| 区域 | CPU 地址 | 输入示例 | Hex 写入范围 |
| --- | --- | --- | --- |
| `1:FLASH` | `8:0000～F:FFFF`，512 KiB | 五位 `84000` → `8:4000`；`FFFFF` → `F:FFFF` | S1 用户区 `8:4000～5FEF` |
| `2:SRAM` | `4:0000～4:7FFF`，32 KiB | 四位 `1234` → `4:1234` | 整个范围 |
| `3:RAM` | `0:8000～0:8DFF`，3.5 KiB | 四位 `8600` → `0:8600` | 整个范围 |

EXE 跳转，左键退回一位，EXIT 取消。输入满位数后继续输入会从头开始；选区域后直接按 EXE 使用显示的默认地址。

Flash 使用 CPU 地址，例如 `84000` 对应文件物理偏移 `0x4000`。RAM/SRAM 保存只写本页实际改过的字节，其他实时变化的字节保持当前值。从其他区域返回 P 时，恢复进入 Hex 前的编程地址。

### Flash 提交与恢复

旧页面编辑器使用 S1/S2 journal（事务备份）：

- **S1**：物理 `[0x4000,0x6000)`；可编辑部分到 `0x5FEF`，末 16 字节为校验元数据，R 可查看。
- **S2**：物理 `[0x6000,0x8000)`，保存恢复副本。

提交按“备份 S1、擦除重写、核对字节与 CRC-16、写完成标记”的顺序执行。中断提交通过有效 S2 恢复 S1。`WRITE ERROR` 保留页面供排查；`RECOVER ERROR` 需要在 PC 恢复完整 Flash 备份。

BASIC 的 FLASHWRITE/ASM 使用原始编程，CALL 直接调用目标；擦除、备份和恢复由程序作者安排，详见 [Flash 原始编程](BASIC_enhancements.md#flash-原始编程与显式擦除)。

## FUNCTION 指令菜单

在 P 按 **FUNCTION**；R 中按 FUNCTION 会回到 P 并打开菜单。菜单使用大字和数字直选。

| 页面 | 按键 |
| --- | --- |
| 类别 | 数字 1～6：ARITH、MOVE、BR、LOADST、STACK、MISC；EXIT 返回 P |
| 指令 | 每页四行，数字 1～4 选择；左/右翻页，首尾循环，尾页空行编号保持当前页；EXIT 返回类别 |
| 操作数 | 数字键输入，ALPHA → 1～6 输入 A～F；左键回退，右键或 EXE 前进 |
| 机器码预览 | EXE 暂存到 RAM 队列；`NEXT 4002 Q02` 表示下一条 PC 与待保存字节数 |

L/ST 字段后有 `SEG --`：输入 0～F 添加立即段前缀，DEL 恢复 `--`，EXE 接受，EXIT 取消。`--` 使用原生单指令访存。XR 选择 0/4/8/12，QR 选择 0/8。共享目录保留原 81 项，并加入 XR/QR/LR/EA 栈操作及 POP PC。

### 保存两条指令

此例写入 `8:4008` 起的四个字节。先在型号副本中备份 S1，并确认目标空间可供使用。

1. 用 GOTO 选择 **4008**。
2. 按 **FUNCTION → 2:MOVE → 1:MOV R,#**，输入 **0、0、1、EXE**；预览应为 `01 00`，再按 EXE 暂存。
3. 按 **FUNCTION → 6:MISC → 右 → 右 → 2:END**；预览应为 `1F FE`，再按 EXE 暂存。
4. 按 **SHIFT → EXE** 保存队列，切换 R 读回 `8:4008`，应得到 `01 00 1F FE`。

队列最多 64 字节，超出时先提交已有内容。事务写入器处理跨页指令、长度变化和分支重定位。P 按 EXIT 后，EXE 保存并退出，EXIT 放弃并退出。

条件分支输入四位绝对目标 PC，按 `(目标−(当前 PC+2))/2` 编码；奇目标、扇区越界和距离越界分别报错。JMP/CALL 使用段 8 的四位 PC；END 编码为原生 RET（`1F FE`）。核验已保存的机器码后，按 **ALPHA → EXE** 执行。

## BASIC 与公共入口

在原生 PROGRAM 编辑器按 **FUNCTION → 右 → 1:NX** 使用 e.basic。完整按键教程与程序见 [BASIC 入门](BASIC_enhancements.md)，参数和副作用见 [语言参考](e.basic.md)。

共享小字入口为 **F:9000**，指针表和补充字模位于 **F:9400 / F:9480**。使用旧段 9 扩展入口的汇编须按新地址重编译；段 9 供原生程序库使用。接口、字符范围和显示状态恢复见 [小字体参考](ROM_small_font.md)。

## 关机签名

按 **SHIFT → AC/ON（OFF）** 显示 Ziyang-Bai 签名；再次按 AC/ON 恢复计算界面。关闭模拟器窗口前，按前面的持久化流程等待落盘。

修改图案时，编辑 [`ziyang_bai.pbm`](../firmware/e5800p/ziyang_bai.pbm)，保持 **96×32** 像素，`1` 表示黑色，再重新 [构建固件](../README.md#从原厂-flash-构建)。资源采用 ASCII PBM，构建时打包为 384 字节，每行 12 字节，高位在左。

## 实现依据

Hex 的 RAM/SRAM 范围来自配套模拟器的 [RAM 映射](https://github.com/telecomadm1145/CasioEmuMsvc/blob/2d26202d56e437654296af85c94a9036bb34ad58/CasioEmuMsvc/src/Models.h) 与 [外部 SRAM 注册](https://github.com/telecomadm1145/CasioEmuMsvc/blob/2d26202d56e437654296af85c94a9036bb34ad58/CasioEmuMsvc/src/Peripheral/BatteryBackedRAM.cpp)，并用实际 3584/32768 字节镜像核对。

小字由 `firmware/e5800p/ui.py` 的 `small_text` 绘制，复用有效 ROM 字形，补齐 `20h..5Fh` 的英文、符号和空白 P，字距 4px、字高 5px。ROM `06` 路径对 M、V、H、# 等字符会从 ROM 起始位置读取字模，因此页面使用补齐后的入口。

关机实现位于 [`logo.py`](../firmware/e5800p/logo.py)：Flash `C:FA66` 检查调用者，返回地址 `0:59D6` 触发签名，其他调用走原保存流程；绘制后接回 `0:59F6`。钩子与点阵位于 `8:1A86`、`8:1C86`，配套 ROM 保持原样。

原生保存经 ROM `0:578E` 备份 SRAM，冷复位经 `0:5900 → 0:5782 → 0:5C9C` 恢复。当前镜像与历史二进制的实际执行范围见 [验证记录](verification.md)。
