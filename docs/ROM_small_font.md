# fx-5800P ROM 小字体调用

| 用途 | 入口 | 字形与字距 |
| --- | --- | --- |
| 数字、十六进制等已确认字符 | ROM `0:041DAh`，`80A0=06` | 3×5，4px，24 字/行 |
| 普通 ASCII 提示 | ROM `0:041DAh`，`80A0=07` | 5×6，6px，16 字/行 |
| 完整大写汇编文本 | e5800p `F:9000h` | 3×5，4px，24 字/行 |

两个入口都从 **段 0 RAM** 读取 NUL 结尾字符串。Flash 常量须先复制到 RAM；正文从 `y=1` 开始，避开状态扫描行。绘制主缓冲后调用 `0:043BEh` 刷新 LCD。

本文地址对应 131072 字节的 fx-5800P Mask ROM，SHA-256 为 `9a190cb85d1c3c1f096dfabf0cd8393580beb59ae603e56871f76b721ce7de75`。其他 ROM 版本须重新核对接口；镜像使用见 [固件指南](e5800p.md)。原始 ROM、完整反汇编 listing 和芯片手册由使用者自行取得并保留本地。

## 接口与内存

ROM 字符串入口为 `BL 0:041DAh`，机器字节 `01 F0 DA 41`；项目文本汇编器写作 `CALL_SYS 0x041DA`。

| 参数 | 含义 |
| --- | --- |
| `R0` | 像素 x，显示宽度 96px |
| `R1` | 像素 y；正文从 1 开始 |
| `ER2` | 段 0 中 NUL 结尾字节串的地址，`R2` 为低字节、`R3` 为高字节 |

字符串使用无前缀访存，按 nX-U8/100 Core Instruction Manual §1.3.4 访问数据段 0。调用者须为字符串和保存的现场分配互不重叠的空间，并在全部绘制调用结束后再释放或复用。

| 全局状态 | 含义 | 调用时的处理 |
| --- | --- | --- |
| `0x80A0` | `06`：3×5；`07`：5×6；`08`：常规大字 | 保存、按需设置、恢复 |
| `0x80A1` | 独立的绘制组合模式 | 只切换字号时保持原值 |
| `0x80A2` | 非零：主缓冲；零：LCD 缓冲 | 使用主缓冲刷新流程时设 `01`，结束后恢复 |

| 缓冲 | 地址范围 | 每行步长 |
| --- | --- | --- |
| 主缓冲 | `0x80E0..0x825F` | `0Ch`，12 字节 |
| LCD 缓冲 | `0xF800..0xF9FF` | `10h`，16 字节 |

ROM 显示区域为 96×32px，坐标检查接受 `x≤5Fh`、`y=0..31`。`06` 的水平步距为 4px，`07/08` 为 6px。关于 `y=0` 的裁切和状态刷新，见 [首行坐标与状态扫描行](#首行坐标与状态扫描行)。

## 完整汇编文本的小字入口

e5800p 提供 `BL F:9000h`，机器字节 `01 FF 00 90`；项目文本汇编器写作 `CALL_SYS 0xF9000`。

| 项目 | 调用契约 |
| --- | --- |
| 坐标 | `R0=x`，取 `0..92` 内的 4 的倍数；`R1=y`，范围 `1..27`，由调用者保证 |
| 字符串 | `ER2` 指向段 0 RAM 的 NUL 结尾字符串 |
| 字符集 | `20h..5Fh`：大写字母、数字和汇编符号；其他非零码显示 `?` |
| 寄存器 | 保持 `XR4`、`R8..R15`；`R0..R3` 为临时寄存器 |
| 绘制 | 直接写 `0x80E0` 主缓冲，每字五条扫描行，水平到 96px 时停止 |

此入口直接按坐标和字模写主缓冲；`80A0/80A1/80A2` 留给 ROM 绘制流程，LCD 刷新由调用者执行。页面通常按六条扫描行排一行文字，第六条留作间距，选中项反色也由页面处理。实现见 [`ui.py`](../firmware/e5800p/ui.py) 的 `small_text`。

### 字模布局与地址迁移

`F:9400h` 是 `20h..5Fh` 的两字节字模指针表，补充字模从 `F:9480h` 开始。指针 bit15 区分低地址 ROM 字模和高地址 Flash 补充字模，表和补充字模使用段 F 读取前缀。每条扫描行取 bits 6..4，以一列空白和三列字形组成 4px 字距。

段 9 留给原生程序库。硬编码旧入口 `9:9000` 的用户汇编须按 `F:9000h` 重编译；寄存器接口保持不变。

## 调用顺序示意

下面给出 **ROM 接口的调用约定**，用于嵌入已有函数。调用者先按自身约定保存 LR/寄存器和 `80A0/80A2`，并在已分配的段 0 栈帧或缓冲区中准备字符串；段 0 RAM 的其他空间继续由原生系统使用。

1. 设置 `80A2=01`；需要整页重绘时，先调用 `0:0409Ah` 清空整个主缓冲。
2. 设置 `80A0=06`，让 `ER2` 指向 `41 42 43 00`（`ABC` + NUL），以 `(x,y)=(0,1)` 调用 `0:041DAh`。
3. 若再绘制普通英文，设置 `80A0=07`，重新设置 `ER2` 指向 `48 45 4C 4C 4F 00`（`HELLO` + NUL），以 `(0,9)` 调用同一入口。两行相隔八像素，共用一次清屏和最终刷新。
4. 调用 `0:043BEh` 刷新，再恢复 `80A2/80A0` 和调用者现场。提前退出路径也须恢复已改变的状态。

步骤 2 的调用片段采用项目文本汇编器语法；进入片段时，`ER2` 已指向有效字符串，`80A0/80A2` 已按上述设置：

```asm
MOV R0,#0
MOV R1,#1
CALL_SYS 0x041DA
```

后续使用 `R0/R1/EA` 前重新赋值。继续绘制紧凑数值行时重新设 `80A0=06`；`HEX` 等普通文字标题使用 `07`。清屏和刷新都保持 `80A0/80A2`，因此清屏也可放在设置字号之后，但必须在首次绘制之前。

实际栈帧与调用方式可参照 [`firmware/e5800p/editing.py`](../firmware/e5800p/editing.py)。归档的 `legacy/tools/isa_menu.py` 的 `show`、`legacy/tools/instruction_view.py` 和 `legacy/tools/program_mode.py` 也先在栈帧准备 NUL 结尾 ASCII，再调用绘制例程。

### 选择可显示的字符

ROM `06` 路径接受以下 ASCII；`00h` 用作字符串终止符：

| 类型 | 码值 |
| --- | --- |
| 空格、括号、符号、数字 | `20h`、`28h–39h` |
| 大写字母 | `41h–46h`（A–F）、`4Fh–52h`（O–R）、`58h–59h`（X–Y） |
| 小写字母 | `61h–66h`（a–f）、`6Eh`（n）、`73h`（s） |

接受码仍可能是空白字形，例如 `P`（`50h`）为 `00 00 00 00 00`。范围外的码会使绘制路径从 ROM 起始位置读取字模；已有实测记录中，`M`、`V`、`#` 均得到 `00 80 D0 70 D0`。因此 `06` 适合已确认的数字和十六进制字形，普通英文用 `07`，完整紧凑汇编文本用 `F:9000h`。

## 32 字节页面 Hex 网格的实用布局

[`firmware/e5800p/editing.py`](../firmware/e5800p/editing.py) 在页面进入时保存 `80A0/80A2`，清屏后设为 `07/01`，退出时恢复。

| 区域 | 绘制方式 |
| --- | --- |
| 四条数据行 | `F:9000h`，`y=1、7、13、19`；每行八组“空格 + 两位十六进制”，合计 32 字节 |
| 底行 | ROM 普通字体，`y=25`；显示段号、地址、当前值、暂存状态，`x=90` 显示 R 或 W |
| 读取模式 | 显示所选 Flash／SRAM／RAM 页的实际字节；S1 元数据只读 |

12×6px 光标格的起点为：

```text
0x80EC + (R5 & 18h)×9 + floor(3×(R5 & 7)/2)
```

逐行异或两字节，偶数列用 `FF F0`，奇数列用 `0F FF`，每行跨 12 字节。全部绘制结束后调用 `0:043BEh` 刷新一次。原生 PROG/ASM 选择页与指令菜单也使用独立栈帧保存和恢复字体设置。

## 首行坐标与状态扫描行

`y=0` 对应 `0x80E0..0x80EB`，供 SHIFT、ALPHA 等状态指示使用。字形写入原语 `0:4350h` 以 `0x80EC` 为正文下界，仍按原始 y 坐标推进字模，因此从 `y=0` 打印会裁切第一条字形扫描行。键盘路径 `1:234Eh → 0:6178h` 会清除并重绘这十二字节，再复制到 LCD；正文和反色框均从 `y=1` 开始。

| 页面区域 | 字体与布局 |
| --- | --- |
| FUNCTION 类别／指令编号菜单、Hex 内存 GOTO | `80A0=08`，5×7 大字，6px 字距、16 字/行；数字直接选择。原生辅助函数 `1:9EC2h` 使用 `y=1、9、17、25` |
| 操作数、机器码预览、P 的 GOTO、指令详情 | `07`，5×6 普通 ASCII |
| Disas | 小字标题 `y=1`；正文 `y=7、13、19`；标签反色 `x=0..39、y=1..6`，指令反色区域按机器码宽度定位，高六条扫描行 |
| Hex | 四条数据行 `y=1、7、13、19` |
| 两种视图的底行 | 普通字体，`y=25` |

## ROM 查证地址

以下反汇编和字节对应本文指定的 Mask ROM。其他 ROM 版本及实体机调用分别核对、记录。

### 字符串读取

- `0x0041E0/1E2`：将 `ER0/ER2` 复制到 `ER8/ER10`。
- `0x004200`：`L R6,[ER10]`（`A0 96`）读取首字节；`0x004202` 遇零退出。
- `0x004214–21C`：调用单字绘制 `0:0422Eh`，然后将指针加一。

### 字号、边界与字模

- `0x0041E4–1F2`：字节 `04 0D 18 0E 10 90 A0 80 06 70 02 C9 06 0D 10 0E` 决定字体步距和每行字数；`0x0041F4` 的 `MOV R15,60h` 给出 96px 宽度。
- `0x004238–23E`：检查 `x≤5Fh`、`y<20h`；`0x004320–32A` 给出有效 y 为 `0–31`。
- `0x004294–30C`：按 `80A0` 逐行读取字模。
- `06` 路径 `0x006A54–66 → 0x006B24 → 0x006AC2 → 0x006F5C–78`：ASCII `A` 映射至 `0x3F2E + 5×13h = 0x3F8D`；字节 `20 50 70 50 50` 为三列五行的 `A`。
- `07` 路径 `0x006A60–74 → 0x0069A4–C2 → 0x006B90–B6`：ASCII `1Ah–7Eh`（含通常可打印的 `20h–7Eh`）映射至 `0x2E78 + 6×(码值−9)`；`H` 在 `0x2FF2`，字节为 `44 44 7C 44 44 44`。

`06` 的字符范围由 `0x006E70–0E2` 检查。范围外的码在 `0x006ED8` 返回 `FFh`，`0x006F66` 将字模指针置零，随后单字绘制读取 ROM 起始数据。

### 缓冲选择、刷新与恢复

- `0x004240–254`：按 `80A2` 选择终点 `0x825F` 或 `0xF9FF`；`0x00443C–464` 对应起点 `0x80E0`／`0xF800` 和步长 `0Ch`／`10h`。
- `0x00582A–832`：初始化写 `80A2=01`、`80A0=08`。
- `0x00409A–0B2`：清零 `0x80E0..0x825F`，执行 `30h` 次、每次 8 字节；`0x0043BE–3E8` 将主缓冲复制到 `0xF800`。两者都保持 `80A0/80A2`。
- `0x0041DA–22C` 在 `0x0041E8` 读取 `80A0`；`0x00422E` 在 `0x004246/256/294` 读取 `80A0/80A2`。
- `0x007550–558/0075A4`：ROM 自身采用保存、临时切换、恢复 `80A0` 的方式。

调用序列中常用指令的编码如下，供核对机器码：

| 指令（ROM listing 记法） | 字节 |
| --- | --- |
| `L R0,080A0h` / `L R0,080A2h` | `10 90 A0 80` / `10 90 A2 80` |
| `ST R0,080A0h` / `ST R0,080A2h` | `11 90 A0 80` / `11 90 A2 80` |
| `PUSH R0` / `POP R0` | `4E F0` / `0E F0` |
| `MOV R0,#01h` / `MOV R0,#06h` | `01 00` / `06 00` |
| `BL 0:0409Ah` / `BL 0:043BEh` | `01 F0 9A 40` / `01 F0 BE 43` |
