# fx-5800P ROM 小字体调用

| 用途 | 入口 | 字形与字距 |
| --- | --- | --- |
| 数字、十六进制等已确认字符 | ROM `0:041DAh`，`80A0=06` | 3×5，4px，24 字/行 |
| 普通 ASCII 提示 | ROM `0:041DAh`，`80A0=07` | 5×6，6px，16 字/行；ASCII `1Ah–7Eh` |
| 完整大写汇编文本 | e5800p `F:9000h` | 3×5，4px，24 字/行 |

两个入口都从段 0 RAM 读取 NUL 结尾字符串。Flash 常量须先复制到 RAM；正文从 `y=1` 开始，避开状态扫描行。绘制主缓冲后调用 `0:043BEh` 刷新 LCD。

本文地址对应 131072 字节的 fx-5800P Mask ROM，SHA-256 为 `9a190cb85d1c3c1f096dfabf0cd8393580beb59ae603e56871f76b721ce7de75`。其他 ROM 版本及实体机调用须另行核对；镜像使用见 [固件指南](e5800p.md)。

## 接口与内存

ROM 字符串入口为 `BL 0:041DAh`，机器字节 `01 F0 DA 41`；项目文本汇编器写作 `CALL_SYS 0x041DA`。

| 参数 | 含义 |
| --- | --- |
| `R0` | 像素 x，显示宽度 96px |
| `R1` | 像素 y；正文从 1 开始 |
| `ER2` | 段 0 中 NUL 结尾字节串的地址，`R2` 为低字节、`R3` 为高字节 |

字符串使用无前缀访存，按 nX-U8/100 Core Instruction Manual §1.3.4 访问数据段 0。调用者须为字符串和保存的寄存器值分配互不重叠的空间，并在全部绘制调用结束后再释放或复用。

| 全局状态 | 含义 | 调用时的处理 |
| --- | --- | --- |
| `0x80A0` | `06`：3×5；`07`：5×6；`08`：常规大字 | 保存、按需设置、恢复 |
| `0x80A1` | 独立的绘制组合模式 | 只切换字号时保持原值 |
| `0x80A2` | 非零：主缓冲；零：LCD 缓冲 | 使用主缓冲刷新流程时设 `01`，结束后恢复 |

| 缓冲 | 地址范围 | 每行步长 |
| --- | --- | --- |
| 主缓冲 | `0x80E0..0x825F` | `0Ch`，12 字节 |
| LCD 缓冲 | `0xF800..0xF9FF` | `10h`，16 字节 |

ROM 显示区域为 96×32px，坐标检查接受 `x≤5Fh`、`y=0..31`。`06` 的水平步距为 4px，`07/08` 为 6px。关于 `y=0` 的裁切和状态刷新，见 [首行坐标与状态扫描行](#首行坐标与状态扫描行)。

## 完整汇编文本的小字入口

e5800p 提供 `BL F:9000h`，机器字节 `01 FF 00 90`；项目文本汇编器写作 `CALL_SYS 0xF9000`。

| 项目 | 参数与行为 |
| --- | --- |
| 坐标 | `R0=x`，取 `0..92` 内的 4 的倍数；`R1=y`，范围 `1..27`，由调用者保证 |
| 字符串 | `ER2` 指向段 0 RAM 的 NUL 结尾字符串 |
| 字符集 | `20h..5Fh`：大写字母、数字和汇编符号；其他非零码显示 `?` |
| 寄存器 | 保持 `XR4`、`R8..R15`；`R0..R3` 为临时寄存器 |
| 绘制 | 直接写 `0x80E0` 主缓冲，每字五条扫描行，水平到 96px 时停止 |

此入口保持 `80A0/80A1/80A2`，由调用者刷新 LCD 和处理选中项反色。

### 字模布局与地址迁移

`F:9400h` 是 `20h..5Fh` 的两字节字模指针表，补充字模从 `F:9480h` 开始，`*` 位于 `F:9086h`。指针 bit15 区分低地址 ROM 字模和高地址 Flash 补充字模，表和补充字模使用段 F 读取前缀。每条扫描行取 bits 6..4，以一列空白和三列字形组成 4px 字距。

段 9 用于原生程序库或 Add-in。使用旧入口 `9:9000` 的汇编须按 `F:9000h` 重编译；寄存器接口保持不变。

## 调用顺序示意

调用 ROM 接口前，按调用者约定保存 LR/寄存器和 `80A0/80A2`，在已分配的段 0 栈帧或缓冲区中准备字符串。段 0 RAM 的其他空间由原生系统使用。

1. 设置 `80A2=01`；需要整页重绘时，先调用 `0:0409Ah` 清空整个主缓冲。
2. 设置 `80A0=06`，让 `ER2` 指向 `41 42 43 00`（`ABC` + NUL），以 `(x,y)=(0,1)` 调用 `0:041DAh`。
3. 若再绘制普通英文，设置 `80A0=07`，重新设置 `ER2` 指向 `48 45 4C 4C 4F 00`（`HELLO` + NUL），以 `(0,9)` 调用同一入口。两行相隔八像素，共用一次清屏和最终刷新。
4. 调用 `0:043BEh` 刷新，再恢复 `80A2/80A0` 和调用前的寄存器值。提前退出时也须恢复已改变的状态。

步骤 2 使用项目文本汇编器语法；进入片段时，`ER2` 已指向有效字符串，`80A0/80A2` 已按上述设置：

```asm
MOV R0,#0
MOV R1,#1
CALL_SYS 0x041DA
```

后续使用 `R0/R1/EA` 前重新赋值。继续绘制紧凑数值行时重新设 `80A0=06`；`HEX` 等普通文字标题使用 `07`。

### 选择可显示的字符

ROM `06` 路径接受以下 ASCII；`00h` 用作字符串终止符：

| 类型 | 码值 |
| --- | --- |
| 空格、括号、符号、数字 | `20h`、`28h–39h` |
| 大写字母 | `41h–46h`（A–F）、`4Fh–52h`（O–R）、`58h–59h`（X–Y） |
| 小写字母 | `61h–66h`（a–f）、`6Eh`（n）、`73h`（s） |

接受码仍可能是空白字形。范围外的码会使绘制路径从 ROM 起始位置读取字模。`06` 适合已确认的数字和十六进制字形，普通英文用 `07`，完整紧凑汇编文本用 `F:9000h`。

## 32 字节页面 Hex 网格的实用布局

| 区域 | 绘制方式 |
| --- | --- |
| 四条数据行 | `F:9000h`，`y=1、7、13、19`；每行八组“空格 + 两位十六进制”，合计 32 字节 |
| 底行 | `F:9000h`，`y=25`；显示地址、当前值、暂存标记 `*` 和 `HEX EXE:EDIT F`／`EDIT 2HEX EXE` |
| 浏览 | 显示 Flash／SRAM／RAM 字节及暂存修改；S1 元数据只读 |

12×6px 光标格的起点为：

```text
0x80EC + (R5 & 18h)×9 + floor(3×(R5 & 7)/2)
```

逐行异或两字节，偶数列用 `FF F0`，奇数列用 `0F FF`，每行跨 12 字节。全部绘制结束后调用 `0:043BEh` 刷新一次。

## 首行坐标与状态扫描行

`y=0` 对应 `0x80E0..0x80EB`，供 SHIFT、ALPHA 等状态指示使用。字形写入原语 `0:4350h` 以 `0x80EC` 为正文下界，仍按原始 y 坐标推进字模，因此从 `y=0` 打印会裁切第一条字形扫描行。键盘路径 `1:234Eh → 0:6178h` 会清除并重绘这十二字节，再复制到 LCD；正文和反色框均从 `y=1` 开始。

| 页面区域 | 字体与布局 |
| --- | --- |
| FUNCTION 类别／指令编号菜单、Hex 内存 GOTO | `80A0=08`，5×7 大字，6px 字距、16 字/行；数字直接选择。原生辅助函数 `1:9EC2h` 使用 `y=1、9、17、25` |
| 操作数、机器码预览、DISASM 的 GOTO、指令详情 | `07`，5×6 普通 ASCII |
| DISASM | 标题 `DISASM EXE:ASM F:MENU` 在 `y=1`；正文 `y=7、13、19`；标题前 24px 反色，所选指令反色区域按机器码宽度定位，高六条扫描行 |
| HEX | 四条数据行 `y=1、7、13、19` |
| 底行 | `y=25`；DISASM 用普通字体显示地址，HEX 用小字显示地址、状态和操作提示 |
